 ⌨️ Keyboard Checker

A simple **Keyboard Key Checker** built using **HTML, CSS, and JavaScript**.  
It detects which key is pressed on the keyboard and displays the key, key code, and other details.

 🚀 Features
- Shows the key pressed (e.g., `A`, `Enter`, `Space`, etc.).
- Displays the **key code**.
- Works with all keyboard keys.
- Simple and responsive design.

---

🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
